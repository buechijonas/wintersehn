# atlas

Frontend for atlas.wintersehn.ch, a place to learn and document. Institutions hold subjects, subjects hold documentations (Markdown with images) and learning sets (flashcards with a study mode). Only signed-in admins can open it. The API lives in `backend/atlas`; Markdown is rendered and cleaned in the backend by `commons`.

```sh
npm install
npm run dev   # http://localhost:5169
```
