# lumon

Frontend for lumon.wintersehn.ch, a personal overview of movies and series. Search with categories, browse series and movies as poster rows, keep a list, upload your own videos and play them. Series data and posters come from TVmaze, movie data from Wikidata, both without an API key, through `backend/lumon`. Uploaded videos form the own media library. Only signed-in admins can open it.

```sh
npm install
npm run dev   # http://localhost:5177
```
