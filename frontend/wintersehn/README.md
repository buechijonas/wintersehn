# wintersehn

Frontend for wintersehn.ch, the personal portfolio: dashboard, about, ethos, CV, countries, projects, media, articles, an Engineering page with architecture diagrams and code highlights, channels and the admin area for all content. Content comes from `backend/wintersehn/content`, sign-in from `backend/wintersehn/accounts`. Shares layout, auth and settings with the other frontends via `../core` (`@core/…`).

```sh
npm install
npm run dev   # http://localhost:5173
```
